# Random Password Generator

A simple and elegant **Random Password Generator** built with HTML, designed to help you create strong and secure passwords with customizable options.

---

## Features

- ✅ Include **Uppercase** letters (A-Z)  
- ✅ Include **Lowercase** letters (a-z)  
- ✅ Include **Numbers** (0-9)  
- ✅ Include **Symbols** (e.g., !@#$%^&*)  

---

## Demo

Try it out live by opening the `index.html` file in your browser and customize your password with the options provided!

---

## How It Works

1. Select the options you want in your password: uppercase, lowercase, numbers, and/or symbols.  
2. Choose the desired password length.  
3. Click the **Generate Password** button.  
4. Your new, strong password will appear, ready to use!

---

## Why Use This?

- Creates **strong and unpredictable** passwords.    
- Easy to use with a clean, user-friendly interface.  
- Customizable based on your security needs.  
- Perfect for securing accounts, apps, and websites.
